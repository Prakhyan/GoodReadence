# GoodReadence identity

GoodReadence is a product of **Casid Studio**. The public ownership line is **© 2026 Casid Studio · GoodReadence**. The product-initiative credit belongs in Help & FAQ.

The current logo is the purple page-stack and sparkle image supplied by the owner, preserved in `assets/brand-source.jpg`. `brand-mark.svg` embeds that exact image on a square black background without redrawing it. It replaces the retired G-and-bookmark monogram. No CC0 dedication or independent rights verification is asserted for the supplied artwork.

Run `node scripts/render-brand-assets.cjs`, then `node scripts/render-social-preview.cjs` to refresh the favicon, install icons and sharing banner. Both use Playwright (set `PLAYWRIGHT_MODULE` when installed outside this project). All exports use the same master, including the artwork's existing padding for Android maskable icons.

Service logos on Contact identify their respective services and retain their owners' rights.
