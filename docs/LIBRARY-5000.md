# Library expansion to 5,000 books

Included in the existing 1.5 feature release as patch 1.5.2.

- Added exactly 3,000 complete editions across 25 genres.
- Preserved all previous 2,000 edition fingerprints and permanent book URLs.
- Full source files remain remote; only metadata and original display covers are deployed.
- Source permissions, creative contributors, complete reading order, assets, supported characters and duplicate works were screened before publication. Screening is not a universal legal certification.
- 20 additions have attributed community ratings; remaining titles stay unrated.
- First-page selection changes per session while pagination and internal navigation retain the order. The no-JavaScript catalogue remains statically crawlable.

See [the expansion process](CATALOGUE-EXPANSION.md) for review controls and limitations.
